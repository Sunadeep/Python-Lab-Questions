# Python-Lab-Questions

Beginner Python exercises covering multiplication tables, star patterns, Fibonacci, lists, tuples, and sets.

## Programs

- Multiplication table
- Right triangle, inverted triangle, and pyramid patterns
- Fibonacci series
- Smallest number and average in a list
- Count occurrences, reverse, and sort a list
- Find common elements in two tuples
- Convert between lists and tuples
- Set union, intersection, and difference
- Remove duplicates from a list using a set

Run a program with:

```bash
python multiplication_table.py
